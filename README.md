# 🤖 AgentAI — Spersonalizowany Agent Sprzedażowy AI

Automatyczny kreator agentów AI dla firm. Uruchamiasz `.bat`, podajesz dane swojej firmy i dostajesz gotowego asystenta sprzedażowego z interfejsem czatu w przeglądarce.

---

## 📦 Zawartość

| Plik | Opis |
|------|------|
| `AgentAI_v3.bat` | Główny instalator — generuje agenta pod Twoją firmę |
| `GenerujAgenta.bat` | Wersja dla klientów — uproszczony kreator |

---

## 🚀 Szybki start

1. Pobierz `AgentAI_v3.bat`
2. **PPM → Uruchom jako administrator**
3. Wypełnij formularz (nazwa firmy, oferta, klienci, klucz OpenAI)
4. Kliknij ⚡ WYGENERUJ AGENTA
5. Przeglądarka otwiera się automatycznie z czatem

---

## ⚙️ Wymagania

- Windows 10 / 11
- Python 3.x → [python.org](https://python.org) (przy instalacji zaznacz **"Add to PATH"**)
- Klucz OpenAI API → [platform.openai.com](https://platform.openai.com/api-keys)

---

## 🎨 Ekran operacyjny

- 💬 **Czat AI** — rozmowa z agentem w czasie rzeczywistym
- ⚡ **Szybkie akcje** — generuj oferty, emaile, analizę klienta jednym kliknięciem
- 📋 **Eksport** — zapisz rozmowę do pliku
- 🔄 **Pamięć kontekstu** — agent pamięta historię rozmowy
